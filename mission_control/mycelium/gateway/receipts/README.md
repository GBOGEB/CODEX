# MissionControl gateway receipts

This directory contains machine-readable receipts generated by the authenticated
MissionControl command gateway.

Receipts record the authenticated GitHub actor, workflow run identity, exact
source SHA, canonical command-envelope digest, allow-listed action, mutation
mode, changed paths, and the non-transfer/non-credit invariants.

The gateway never writes directly to `main`. Non-dry-run executions publish
changes to an automation branch and request review through a pull request.
Receipts must not contain access tokens, secrets, or private payloads.
