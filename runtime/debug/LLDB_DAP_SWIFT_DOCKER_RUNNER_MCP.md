# LLDB-DAP Swift Docker Runner MCP KEB Lane

This lane modernizes the debug/runtime proof path as one MIP pulse:

- Modernize: classify stale or dormant debug, Docker, runner, and MCP surfaces.
- Innovate: turn LLDB-DAP/Swift debug into an executable KEB receipt.
- Perpetuate: keep the receipt runnable through GitHub runner artifacts.

## Victory Chain

1. LLDB-DAP census PASS.
2. Swift/debug surfaces classified.
3. One real Swift target is compiled with debug symbols.
4. LLDB executes the target and records step evidence greater than zero.
5. CODEX emits an exact-head KEB receipt.
6. ABACUS consumes that exact receipt as DOW evidence.
7. cryoplant records ACCEPT / REJECT / DEFER child disposition.

## Evidence Rule

Structural discovery is allowed to pass the census, but it is not DoV. DoV only passes when
the macOS probe emits a receipt with:

- `probe_status: ACCEPT`
- `dov_status: PASS`
- `minimum_victory_condition.real_probe_steps_gt_zero: true`
- exact `GITHUB_SHA`
