What actually changes between iterations?

Snapshot-based evidence, not live CI
Actual: Code Purple seed was committed and PR #984 was opened. At first readback 49 check records existed; two checks were SUCCESS, Ruff NEUTRAL and others pending. Merge admission withheld.

What can learn?

Observed failures, elapsed time, root cause, reusable regression guards, stale/pending evidence and the lowest-cost safe next method. Not new LLM weights, a self-approved policy, or inferred green CI.

What gets forwarded?

Sanitized, exact-proven fixtures, methods, receipts or guard candidates. A different repo must independently validate and accept its own consumer proof. No permission, security or QPS authority carries over.

Gate: The documented candidate is not equivalent to executed/admitted improvement. New commits invalidate previous exact-head checks. Re-read the current PR, security review and CI before any merge or propagation.
