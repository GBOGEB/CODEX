# CODEX side of the roundtrip

1. Pull or clone CODEX outside OneDrive.
2. Keep this subfolder source-only.
3. Build from the local private-control clone, not from public data.
4. Write only a sanitized release pointer back to CODEX.
5. Commit/push source, schemas and pointer metadata after review.
6. Store generated outputs in the local artifact repository and OneDrive.
