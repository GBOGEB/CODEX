# PCA KPI guide

Useful generic diagnostics:

- explained variance ratio per component;
- cumulative explained variance;
- component count required for a chosen threshold;
- compression ratio;
- eigenvalue condition number;
- loadings and top absolute feature contributions;
- retained-feature communality;
- reconstruction MSE/RMSE and maximum absolute error.

A PCA score is a coordinate in a fitted statistical model. It is not automatically a priority, risk, engineering-acceptance, or Bradley-Terry score. Any domain interpretation belongs to the consuming system.
