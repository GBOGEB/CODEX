Model

JT envelope: ṁJT·hHP(T3) + Q = L·hl,sat + (ṁJT − L)·hLP(T7), with T3 = T7 + 0.2 K.
Brayton envelope: turbine inlet solved so the η = 0.75 expansion ends at T7; ṁt from the cold-box energy balance with a 3 K warm-end difference.
Optimum: golden-section minimum of the compressor (LP return) flow. Isothermal power: ṁHP·(R/M)·T·ln(PH/PL).
